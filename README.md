# application_documents
Refactoring & Weiterentwicklung: Vom Prototyp zum soliden Release  Wer das Programmieren lernt, will oft zu viel auf einmal. Mein Anspruch an Codequalität und saubere Architektur war früh sehr hoch – so hoch, dass ich Ideen lieber neu startete, als unsauberen Code stehenzulassen.  Auf dieser Seite zeige ich den nächsten Schritt meiner Entwicklung: Code-Refactoring und konsequenter Projektabschluss. Ich nehme frühere Entwürfe und Programmieransätze, seziere die Schwachstellen der Architektur und baue sie mit modernem, nativem JavaScript, semantischem HTML und modularem CSS komplett neu auf.  Jedes Projekt hier beweist zwei Dinge: Meinen Willen, Probleme bis zur Wurzel zu durchdringen, und die Disziplin, eine Codebasis sauber, getestet und funktionsfähig ins Ziel zu bringen.
